# DESAFIO I - FRONTEND

Projeto dedicado a aplicar os conhecimentos em HTML, CSS e Vanilla Js.

## Funcionalidades do projeto:
- Navegação pelas páginas de Desktop, Adoptable Pets e Success Page.
- Botão Donate clicável abrindo o Donate Modal.
- Botão Apply to Adopt clicável abrindo Adopt Modal.
- Validações dos inputs com HTML.
- Validação dos formulários e redirecionamento das páginas.
- Outros botões funcionais: View Adoptables e Subscribe.

## Abrir e rodar o projeto:
Após baixar o projeto você pode abrir usando o Live Server do VSCode ou abrir a pasta do projeto, ir para **pages**, **desktop_page** e abrir o arquivo **index.html**.

**OBS.:** O projeto ainda não é responsivo, usar largura máxima de 1512px, qualquer quebra de layout, por favor diminua sua tela.
